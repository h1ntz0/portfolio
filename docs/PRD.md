# Product Requirement Document

# Project

GitHub Profile Website

---

# Vision

Membangun GitHub Profile Website yang tidak hanya menjadi portfolio, tetapi juga menggambarkan perjalanan belajar, pengalaman, project, dan aktivitas pengembangan software secara profesional.

Website harus memberikan kesan bahwa pemiliknya aktif, konsisten belajar, memiliki kualitas engineering yang baik, serta memiliki ketertarikan pada Software Engineering, QA Automation, AI, dan Open Source.

---

# Goals

Meningkatkan personal branding.

Mempermudah recruiter melihat kemampuan.

Menampilkan project secara menarik.

Menjadi pusat dokumentasi perjalanan belajar.

Mudah diupdate.

SEO friendly.

Fast loading.
